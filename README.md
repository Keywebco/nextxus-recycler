# NextXus Recycler

The Technology Reconstruction Lab of the NextXus HumanCodex Federation. The Recycler takes external tools apart, strips the tracking and subscriptions, and rebuilds the useful core as free software anyone can run. For people who want the tool without the rent.

**Live:** https://keywebco.github.io/nextxus-recycler/

## How a reconstruction works

Pick a paid or locked-down tool, take it apart, keep what is genuinely useful, throw away the tracking and the billing, and rebuild it on free hosting in plain HTML. If a tool adds nothing the Federation lacks, skipping it counts as a result too.

## Reconstruction targets

- **AI-visibility scanner** — Rebuild the core check of commercial AI-search visibility scanners (about $99/month) in Python. High priority.
- **Self-hosted bookmark and knowledge manager** — Fork the MIT-licensed KaraKeep, with semantic search, mapped onto the Library and Archives.
- **Backup coding agent** — CodeWhale, MIT-licensed, kept in reserve as a second builder so there is no single point of failure.

## Completed builds

- **Federation Press Corps** — Replaced a paid newsletter platform. Articles and weekly digests publish to free GitHub Pages; the outside service was removed on 2026-09-30.
- **OneKey** — Covers the core job of a password manager. Passwords are calculated on your device from what you remember: no vault to breach, no subscription.
- **Federation Browser Base** — The multi-window workspace, in a single HTML file with zero dependencies.
- **Sovereign Knowledge OS** — A self-indexing knowledge base on free hosting, no account required.
- **Roger Sim AI** — A talking AI persona that uses the browser's built-in speech for its voice. Static front end, low-cost back end.
